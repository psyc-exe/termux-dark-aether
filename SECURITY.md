# Security policy

## Reporting a vulnerability

Email security reports to `security@aether-project.org`. Use a PGP key
(4096-bit RSA or 2048-bit ECC) signed by your GitHub identity.

Include:
- Description of the vulnerability
- Steps to reproduce (install steps, environment)
- Impact assessment
- Proposed fix or mitigation (optional)

We will:
1. Acknowledge receipt within 48 hours
2. Work with you to triage and patch
3. Coordinate CVE assignment if needed
4. Credit you in the advisory (with your permission)

Do NOT open a GitHub issue for security-sensitive bugs — email first.
